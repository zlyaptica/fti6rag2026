# RAG-система на базе Telegram-бота

Система позволяет искать информацию на вопрос пользователя во базе знаний, для форматирования ответа и удаления лишней информации из найденной информации используется LLM. В качестве базы знаний выбрана ChromaDB, которая хранит факты в векторном представлении и ищем похожий текст через векторы.

| Команда | Описание                                             |
| -------------- | ------------------------------------------------------------ |
| `/start`       | Запустить бота                                  |
| `/help`        | Показать справку                              |
| `/add`         | Добавить данные в векторную базу |
| `/get_all`        | Показать все сохранённые данные  |
| `/search`      | Поиск по базе знаний                       |
| `/generate`       | Генерация текста на основании знаний LLM            |


## Описание кода

Код модуля бота
``` python
# состояния системы
class AddingInDB(StatesGroup):
    entering_text = State()
    llm_generate = State()
    search_fact = State()

# обработчик команды /add
@router.message(StateFilter(None), Command("add"))
async def command_add_fact_handler(message: Message, state: FSMContext):
    await message.answer(text="Введите текст, который хотите добавить в базу знаний:")
    # переход в состояние ввода текста (запроса)
    await state.set_state(AddingInDB.entering_text)

# обработчик состояния ввода текста
@router.message(AddingInDB.entering_text)
async def handle_new_text(message: Message, state: FSMContext):
    await state.update_data(entering_text=message.text)
    processing_message = await message.answer("Обрабатываем ваш текст...")

    # вызов метода бд для добавления факта
    result = chromadb_client.insert_query(message.text)  
    print(f"{message.from_user.id} добавил {message.text}")

    await processing_message.delete()
    await message.answer("Запись добавлена!", reply_markup=help_keyboard)

    # очистка состояния, переход в начальное состояние
    await state.clear()
```

Код модуля БД
``` python
class ChromaDB:
    def insert_query(self, text: str, metadata: dict = None) -> None:
        doc_id = str(uuid.uuid4())
        self._collection.add(
            documents=[text],
            ids=[doc_id]
        )    
```

## Записи векторной БД

> * В базу добавлено: Вайб-кодинг (Vibe coding) — это стиль разработки, при котором ИИ-агент пишет код по текстовому описанию, а человек выступает в роли «креативного директора», формулируя идеи, проверяя результат и задавая общий «вайб» продукта. Это способ создания ПО через естественный язык, делегирующий рутину генеративным моделям.
> * Bidirectional Encoder Representations from Transformers (BERT) — это языковая модель, представленная в октябре 2018 года исследователями из Google. Она учится представлять текст в виде последовательности векторов с помощью самоконтролируемого обучения. В ней используется архитектура трансформера, состоящая только из кодировщика. BERT значительно улучшила современный уровень развития больших языковых моделей. По состоянию на 2020 год BERT является повсеместным эталоном в экспериментах по обработке естественного языка (NLP).
> * Физика элементарных частиц развилась из ядерной физики, и эти две области обычно преподаются в тесной взаимосвязи. Ядерная астрофизика, то есть применение ядерной физики к астрофизике, играет ключевую роль в объяснении внутреннего устройства звезд и происхождения химических элементов.
> * Ассоциативный футбол, более известный как футбол или соккер, — это командный вид спорта, в котором две команды по 11 игроков почти исключительно с помощью ног перемещают мяч по полю. цель игры — забить больше голов, чем соперник, переправив мяч за линию ворот в прямоугольные ворота, защищаемые противником.

## Промпты для общения с LLM
### Промпт для прямого запроса к LLM без использования базы знаний
```
Ответь кратко на вопрос пользователя.
```

### Промпт для прямого запроса к LLM с использованием базы знаний
```
Пользователь хочет получить ответ на этот вопрос: {}.\n 
Твоя задача - проанализировать вопроса пользователя и найденную информацию,
исправить ошибки форматирования, удалить иинформацию, которая не относится к теме.
От себя ничего не придумывай, используй только факты, найденные в базе знаний.
Используй русский ответ для ответа.
```

# Заключение 
При использовании фактов из базы знаний сервис выдает ответ, похожий на то, что написано в базе. LLM ничего не выдумала, что было указано в промпте. Сгенерированный на знаниях LLM ответ не дал четкого ответа и получил гораздо больший объем текста.
