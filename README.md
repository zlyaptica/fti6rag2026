# ПЕТРГУ ФТИ 6 КУРС | РАЗРАБОТКА RAG

**RAG (Retrieval-Augmented Generation)** — это подход, при котором генерация ответа большой языковой модели (LLM) осуществляется на основе данных, полученных в результате поиска во внешних источниках (файлы, базы данных, интернет и другие). 

RAG объединяет два основных процесса — извлечение и генерацию:
* Извлечение информации. При поступлении запроса система сначала ищет релевантные материалы в базе данных или корпусе документов.
* Генерация ответа. Найденные тексты передаются в LLM, которая на их основе формирует осмысленный и точный ответ, учитывая как содержание источников, так и формулировку запроса.

## Запуск Телеграм бота

Создайте своего бота при помощи бота телеграм @BotFather и получите токен бота, затем введите его в .env файл. Лучшим решением будет создать файл .env.local, идентичный .env и записать токен туда, чтобы не выложить его на репозиторий с коммитом.

Запустите приложение с использованием докер:
```
docker compose up --build -d
```
Без использования докера:
```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py
```
